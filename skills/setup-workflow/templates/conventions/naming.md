# Naming conventions

Conventions for file and folder names in this repository. A skill that creates a file names it by its own rule.

**Keep a name a tool requires exactly as the tool requires it**, such as `package.json`, `Dockerfile` or `.github/workflows/`.

**Name a path in snake_case when code imports it or reads it**: packages, modules, and the config, SQL, prompt and data files an app loads.

**Name every other file and folder in lowercase kebab-case**, such as `docs/conventions/`.

**Keep the standard files uppercase**: `README.md`, `AGENTS.md`, `CLAUDE.md`, `ARCHITECTURE.md`, `GLOSSARY.md`, `SKILL.md`.
