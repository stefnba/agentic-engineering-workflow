## Results of the last run

- **Write mode on `rca/adapters/` after the one-chain and step-label rules**, against the README committed before them: the context diagram fell from 11 nodes to 9 with one chain drawn and the other callers named in prose — the one-chain sentence in the template's Where the code sits comment; every step label carries a code name, such as `Path.rename(): extract/`, and each sequential step has its own node — the step-label and one-node-per-step rules; Responsibilities fell from 7 bullets to 5 and Not here from 5 to 4, within the caps — the cap count in the verify step. The README is 223 lines against 265. Still improvised: the mechanism of a directory of independent adapters, a home for a reference table such as the run layout, whether prose counts toward the example's 30 lines, how to draw state a crash leaves behind, and aligning tables for markdownlint's MD060.

- **Write mode with the notation** on `rca/composition/`, about 250 lines with no single entry function, plus an independent review of the skill change: the agent kept to the template's opening and wrote names in the notation's forms. It improvised where the notation had no rule: a directory whose job is calls in sequence — the entry-point sentence in the locate step; a constructor call, nested functions, enum members, package functions — the Names table rows; legend words for data and decision nodes — the kinds table's Legend word column; one node for three adapters — "several things of one kind"; reading `.env` files for the example — the no-secrets-file guardrail; machine paths in outputs — the path-prefix exception in the Worked example comment. The review found `<OrderForm>` renders blank in Mermaid and `{run_id}` and `<T>` overloaded angle brackets — the escaping rule and braces for varying parts; a port drawn as I/O — the interface-as-Code rule; and the per-section home rule repeating one name four times — home at first mention per document.

- **Review mode** on a copy of a real code README with three planted errors (a removed function name, a wrong input in a table, an example error line the code cannot print): all three found and fixed. It also caught inline example values written by hand — "Show only outputs and values you produced". The agent let the template outrank reviewer findings without a rule saying so — the template-wins line in the fresh-reader step.
- **Write mode** on a package of about 630 lines: every name resolved and every output matched a fresh run. The agent improvised on which function is the entry point, on a long output, on running two variations, and on an example script nobody can rerun — the entry-point sentence in the locate step, "Capture every output verbatim", "at least one variation", and the report's script line.
- **Triggering**, judged from descriptions only: "Document this module" lost to a generic documentation skill until the description led with "document or explain"; "How is this structured?" goes to the architecture skill, which is right for an app but not for one package.
